This is a project to convert the scenarios of the old janes fleetcommand game into the spiritual successor Sea Power.

## Disclaimer
These are two different games made by differnt companies and were released decades apart
- This project implements a best effort of conversion
- Not everything can be converted 1:1 right now
    - Not all units from Fleet Command exist in Sea Power
    - Not all trigger functionality from Fleet Command has a analog in Sea Power

## Working principle
1. Parsing of the original Fleet Command scenario files which use a highly custom file format into json files which are far easier to work with (this step can be considered complete)
2. Converting the intermediate representation into Sea Power sceneraio files

## Website
This project includes a small helper website which can be used to visualize the Fleet Command scenario files.

## Tests
We have some simple tests. Use them and mantain them.

## Coding guidelines
- Don't put sceneario specific stuff in the converter, the converter should stay mostly general.

## Web Search
Don't search anything Sea Power or Fleet Command related on the web. There is so little usefull about this (or extremely outdated) on the web that it is pointless.
